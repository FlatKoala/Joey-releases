# Joey releases

  Installation packages for Joey by Koala Consulting (Ubuntu 26.04, x86-64).
  Installed Joeys update from here automatically; see the License page in Joey.

  Manual install: download the .deb of a release, then
      sudo apt install ./joey_<version>_amd64.deb
  Every package is signed (.deb.asc). Joey is proprietary software;
  third-party licences are listed in /usr/share/doc/joey after installation.
